# 雾岭手记

## 沿途记录

清晨的雾沿着山脊散开。用 **粗体** 标记关键路况，用 *斜体* 写下个人观察，再把记录保存为 `ridge.md`。最新的安排见[路线详情](#路线详情)，~~旧路线~~已停用。

每 10 m^2^ 收集到 12 L H~2~O。最新路况从 [-干燥-] 改为 {+湿滑+}。从入口的 :compass: 标记出发。

> 在同一个垭口，隔五分钟再看一次。
>
> > 只看一眼很难判断天气，留意雾和风的变化。

### 路线详情

| 站点 | 海拔 | 路况 |
| :--- | ---: | :---: |
| 杉林口 | 720 m | 开放 |
| 林间浅溪 | 610 m | 湿滑 |
| 旧石桥 | 645 m | 可休息 |

> 过溪时沿碎石路走。==湿石头容易打滑。==

> [!IMPORTANT]

> [!WARNING]
> 只有看得见踏脚石时才过溪。

> [!CAUTION]
> 远离旧石桥下的河岸。

### 徒步安排

1. 从杉林口出发。
2. 过浅溪，沿有路标的小径前行。
   1. 在第一处标记旁确认水深。
   2. 找到对岸的路标。
3. 到旧石桥后折返。

- 带足往返需要的水。
- 准备一件轻便雨衣。
  - 把雨衣放在背包上层，方便取用。

#### 行前清单

- [x] 保存路线。
- [x] 检查溪水水位。
- [ ] 记录返程时间。

##### 天气窗口

雾散后的能见度最好。手记里的海拔都是近似值。[^elevation]

###### 记录约定

海拔用米，距离用千米。手记中的每条路线都从同一个入口起算。

### 代码与公式

```js title="trail-time.js" {3,5}
// 第一站的测量结果。
const altitude = 720
const distance = 4.2

console.log(`杉林口：${altitude} m`)
```

步速为 $v = 3$ km/h、路程为 $d = 4.2$ km 时，可以用下面的公式估算步行时间。

$$
t = \frac{d}{v} = \frac{4.2}{3} = 1.4\ \mathrm{h}
$$
